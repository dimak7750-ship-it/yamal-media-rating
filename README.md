# Рейтинг пабликов Ямал-Медиа

Страница строит 9 картинок с рейтингом пабликов холдинга за неделю: ВКонтакте, МАКС и Telegram, по трём метрикам на каждую площадку — прирост подписчиков, ER и просмотры.

## Как пользоваться

Откройте https://dimak7750-ship-it.github.io/yamal-media-rating/. Там сразу показан рейтинг за последнюю неделю.

- Неделю и неделю для сравнения выбирают в выпадающих списках. В списке есть все недели из сохранённых файлов.
- Лишние ресурсы можно снять в блоке «Ресурсы в рейтинге». Выбор запоминается в этом браузере.
- Кнопка «Скачать все 9 PNG (zip)» скачивает все картинки, кнопка «PNG» под картинкой — одну.
- «Предпросмотр файла…» строит картинки по xlsx с вашего компьютера. На сайт этот файл не попадает.

## Как обновить данные

1. Положите новый файл съёма в папку `data/raw/` под именем, равным дате конца недели: `2026-10-04.xlsx`.
   Это можно сделать прямо на github.com: откройте папку `data/raw` → Add file → Upload files → Commit.
2. GitHub Actions соберёт `data/weeks.json` из всех файлов в `data/raw` и опубликует сайт. Обычно это занимает 1–2 минуты.
3. Если одна и та же неделя есть в нескольких файлах, берётся версия из файла с более поздним именем.
4. Если в файле не хватает колонок, сборка остановится, и на сайте останутся прежние данные. Ошибку видно во вкладке Actions.

Локальная проверка: `node tools/build-data.js`.

## Что ожидается в файле

- Листы недель называются по маске `ДД-ДД.ММ` (например, `21-27.09`) или начинаются с заголовка «Недельный съём · 21–27.09.2026».
- На каждом таком листе есть строка заголовков: `Площадка | Ресурс | Публикаций | Просмотры | … | Лайки | … | Подписчики | Прирост подписчиков`. Колонки находятся по названию, поэтому их порядок не важен.
- Строки «Итого …» в рейтинг не входят. По ним страница сверяет суммы и выводит предупреждение, если что-то не сходится.
- Одноклассники не учитываются.

Если название колонки изменится, страница не станет ничего считать и покажет, какой колонки не хватает.

## Метрики

| Метрика | Формула |
|---|---|
| Прирост подписчиков | колонка «Прирост подписчиков» за неделю; у столбца подписано «было» — прирост прошлой недели |
| ER | лайки за неделю ÷ подписчики ÷ 7 × 100% — средняя доля подписчиков, ставящих лайк за день (аналог ER Page) |
| Просмотры | колонка «Просмотры» за неделю; Δ — % к прошлой неделе |

▲/▼ показывает смену места в рейтинге относительно недели сравнения, считая только выбранные ресурсы.

## Устройство

Страница — это `index.html`. Разбор xlsx вынесен в `parser.js`: он общий для страницы и для сборки `tools/build-data.js`. Публикацию делает `.github/workflows/pages.yml`. В `lib/` — [SheetJS](https://sheetjs.com) 0.18.5 (Apache-2.0) и [JSZip](https://stuk.github.io/jszip/) 3.10.1 (MIT). В `fonts/` — шрифт Manrope (OFL). Внешних запросов страница не делает.

`src.html` — исходник с плейсхолдером `__LOGO__`. Чтобы пересобрать `index.html`:

```bash
python3 -c "s=open('src.html').read();open('index.html','w').write(s.replace('__LOGO__',open('logo.b64').read()))"
```
