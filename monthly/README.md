# Итоги месяца по соцсетям редакций Ямал-Медиа

Сайт: https://dimak7750-ship-it.github.io/yamal-media-rating/monthly/

Лежит в репозитории недельного рейтинга, в папке `monthly/`. Недельные файлы и их сборка не трогаются.

Страница заменяет таблицу «ИТОГИ … МУНИЦИПАЛЬНОЕ» и считает уже все редакции. 13 муниципальных ранжируются вместе. Окружные и тематические идут отдельными блоками, у каждого блока свои суммы. Площадки: ВК, ОК, ТГ, МАКС. Каждый месяц сравнивается только с прошлым.

## Как обновить месяц

1. На github.com откройте папку `monthly/data/raw`, затем Add file → Upload files.
2. Файлы перетаскивайте в папку месяца: в поле имени файла допишите `2026-10/` перед именем, тогда GitHub создаст папку. В папку месяца кладётся:
   - «Статистика охваты и просмотры …xlsx» — просмотры и охваты (обязательно);
   - недельный съём, ближайший к концу месяца — подписчики (обязательно, один файл). Дата среза берётся из строки «снято …» и выводится на странице;
   - выгрузки barkov за месяц по всем каналам: `vk.barkov.net-wallposts-…csv`, `vk.barkov.net-tgwallposts-…csv`, `vk.barkov.net-okwallposts-…csv` — посты и лайки;
   - вместо barkov можно положить выгрузки Popster по постам (`Popster_ВК_посты_….xlsx`, `Popster_ТГ_посты_….xlsx`) и админские выгрузки групп ОК (`…ok_group<ID>_….xls`), удобно в подпапки `popster/` и `ok_admin/`. Если по одному каналу есть несколько выгрузок, берётся та, что начинается раньше всех в месяце (обрезанная выгрузка barkov проигрывает полной из Popster). Канал с сотней и больше постов, у которого выгрузка начинается позже 4-го числа, а в прошлом месяце были просмотры, считается обрезанным: посты «н/д»;
   - `МАКС_посты_….xlsx` за месяц (лист «Итог по каналам»: Ресурс | Публикаций | … | Лайки) — посты и лайки МАКС.
3. Нажмите Commit changes. Через 1–2 минуты GitHub Actions пересоберёт `monthly/data/months.json` и обновит сайт (недельный тоже пересобирается, это нормально).

Если в обязательном файле нет нужной колонки, месячная сборка остановится, и месячная страница останется на последних данных, сохранённых в репозитории. Недельный сайт при этом публикуется как обычно. Текст ошибки (какой файл, какой колонки нет) виден во вкладке Actions, в шаге «Собрать monthly/data/months.json». Если какой-то необязательной выгрузки нет, сайт соберётся, а посты и ER этой площадки будут «н/д». На странице это видно в разделе «Пометки к данным».

Проверить у себя: `node monthly/tools/build-data.js`.

## Откуда какие цифры

| Метрика | Источник | Как считается |
|---|---|---|
| Просмотры ВК, ОК, ТГ, МАКС | «Статистика…», лист года, колонка месяца | как в файле |
| Охваты (только ВК и ОК) | «Статистика…», колонка месяца в блоке «Охваты» | если в файле месяца колонка пустая, берётся из «Статистики» следующего месяца, на странице есть пометка |
| Подписчики | недельный съём, колонка «Подписчики» | на дату среза; прирост = срез месяца − срез прошлого месяца |
| Посты, лайки | barkov (ВК, ТГ, ОК — классы); если barkov нет — Popster (ВК, ТГ) и админка ОК (посты = лист Topics, лайки = LIKES листа Actions); «МАКС_посты» | посты месяца по дате публикации, строки не удаляются; чужие владельцы (репосты губернатора и т. п.) не учитываются, список выводится в пометках |
| Отдача поста | просмотры ÷ посты | |
| ER | лайки ÷ подписчики ÷ дней в месяце × 100% | как в недельном рейтинге |

Прошлый месяц берётся из его собственной папки, поэтому цифры уже сданного месяца задним числом не меняются. Рост считается по тем ресурсам и площадкам, у которых цифра есть в обоих месяцах. Если сравнение неполное, рядом стоит ✱.

## Служебные файлы

- `data/resources.csv` — справочник: редакция, блок, площадка, название строки в «Статистике», ссылки и ID каналов (по ним сопоставляются выгрузки barkov), название в съёме. Новый паблик добавляется сюда.
- `data/notes.csv` — пометки к данным (известные косяки). Месяц `*` значит «показывать во всех месяцах».
- `ручные_данные….csv` в папке месяца (Площадка;Редакция;Метрика;Значение;Источник) — для того, чего нет в файлах. Такие данные заполняют только пустые клетки. Сейчас так сделана база июля (из «ИТОГИ ИЮЛЯ») и просмотры МАКС за август (коннектор 04.09).
